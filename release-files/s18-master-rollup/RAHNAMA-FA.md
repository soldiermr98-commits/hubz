# راهنمای نصب — بستهٔ جامع و یکپارچهٔ S18 «ارتقای کامل از پایه تا S18»

**تاریخ ساخت:** ۱۴۰۵/۰۸/۲۱ — **نام بسته:** `hamihub-full-upgrade-to-s18.zip`
**نسخه دارایی‌های عمومی:** `public.css?v=s18.0` و `public.js?v=s18.0` و موتور نقشه `?v=s18`
**نوع بسته:** Master Rollup — یک فایل ZIP واحد برای رفتن از «نسخهٔ پایه (تا مایگریشن 012)» به آخرین نسخهٔ سایت، بدون نیاز به نصب ترتیبی بسته‌های قبلی.

---

## ۱) این بسته برای چه ساخته شد؟

تا امروز تغییرات در چند بستهٔ افزایشی جدا (S7 تا S9 و S16 و S17) تحویل شده بود و نصبشان ترتیب می‌خواست. این بسته **همهٔ تغییرات تأییدشده تا امروز را یکجا** دارد تا روی هاست دایرکت‌ادمین فقط یک بار اکسترکت کنید و یک بار «اجرای مایگریشن‌ها» را بزنید:

- **S7:** ارتقای UI/UX عمومی و پنل + رفع خطای information_schema
- **S8:** پشتیبانی بنر GIF متحرک + پاک‌سازی کامل رسانهٔ بنر هنگام حذف
- **S9:** ماژول آمار (تجمیع روزانه + لاگ خام + خروجی CSV + پاک‌سازی خودکار) + رفع خطای SQL 1064 + بازنویسی Base-URL هوش مصنوعی
- **S16:** رفع خطای ۵۰۰ جستجو + ریدیزاین صفحه جزئیات کسب‌وکار + سیستم دیدگاه‌ها (سؤال امنیتی + باز شدن در تب جدید)
- **S17:** مسیریابی هوشمند (دکمهٔ اصلی گوگل با مختصات/Place ID، دکمه‌های نشان و بلد، بیکن آمار) + نقشهٔ انتخاب مکان درگ‌شونده در پنل + Paste سریع لینک گوگل‌مپ + قفل مختصات دستی (مایگریشن 014)
- **S18 (جدید):** گزارش «مختصات پرریسک — مرکز پلی‌گون OSM» در پنل ادمین: فهرست کسب‌وکارهایی که نقطهٔشان از مرکز هندسی پلی‌گون OSM (`way/…` یا `relation/…`) درآمده و هنوز دستی تأیید نشده (`coords_source != 'manual'`)؛ با یک کلیک بازشان می‌کنید و با همان Paste سریع اصلاحشان می‌کنید. بعد از ذخیره، خودکار از گزارش خارج می‌شوند.

**مایگریشن‌های دیتابیس داخل بسته:** همهٔ 001 تا 020؛ سه مایگریشن جدید یعنی `013_analytics_and_ai_logs`، `014_coords_source` و `020_business_comments` در دکمهٔ «اجرای مایگریشن‌ها» یک‌جا اجرا می‌شوند (مایگریشن‌های قبلی که قبلاً اجرا شده‌اند خودکار رد می‌شوند).

## ۲) داخل ZIP چیست؟

| مسیر | محتوا |
|---|---|
| `app/` | کل هستهٔ PHP سایت (Controllers, Core, Services, ThirdParty) — آخرین نسخهٔ همه |
| `public_html/` | کل سایت عمومی + پنل ادمین بیلدشده + دارایی‌ها (CSS/JS/فونت لوکال/موتور نقشه) |
| `database/migrations/` | هر ۱۵ فایل مایگریشن (001 تا 020) |
| `cron/worker.php` | ورکر زمان‌بندی |
| `bin/` | ابزارهای CLI (`migrate.php`، `create-admin.php`) |
| `scripts/build_s18_master_rollup.py` | اسکریپت ساخت همین بسته (برای شفافیت و بازتولید) |
| `INSTALL-FA.md` | همین راهنما |
| `MANIFEST-SHA256.txt` | اثر انگشت SHA-256 تک‌تک فایل‌های بسته |

## ۳) عمداً داخل ZIP نیست (دست نمی‌خورد)

- **`config/config.php`** — اتصال دیتابیس و کلیدهای سایت شما دست‌نخورده می‌ماند (هیچ فایلی از پوشهٔ `config/` در بسته نیست).
- **`collector-remote/`** و **`ai-worker/`** — سرویس‌های جدا با کانفیگ اختصاصی خودشان؛ در این ارتقا تغییری نکرده‌اند.
- **`storage/`** — وضعیت نصب و لاگ‌های خودِ هاست.
- **`public_html/cache/`** و **`public_html/uploads/`** — کش و رسانه‌های آپلودشدهٔ خود شما.
- فایل‌های توسعه (src، tests، docs، node_modules، بسته‌های قدیمی release-files) — روی هاست کاربردی ندارند.

## ۴) پیش‌نیازها (الزامی)

1. **بکاپ فایل‌ها:** در فایل‌منیجر دایرکت‌ادمین، پوشهٔ سایت (شامل `app` و `public_html`) را به یک پوشهٔ بکاپ مثل `backup-s18/` کپی کنید.
2. **بکاپ دیتابیس:** phpMyAdmin → انتخاب دیتابیس → Export → Quick. این بکاپ مخصوصاً پیش از اجرای مایگریشن‌ها ضروری است.

## ۵) مراحل نصب (به همین ترتیب)

1. فایل ZIP را روی کامپیوتر خودتان از حالت فشرده خارج **نکنید**؛ همان ZIP را آپلود کنید.
2. در فایل‌منیجر دایرکت‌ادمین، ZIP را به **پوشهٔ مادرِ `public_html`** (همان‌جایی که کنارش پوشهٔ `app` است) منتقل و **Extract** کنید؛ گزینهٔ بازنویسی (Overwrite) را تأیید کنید. ساختار پوشه‌ها داخل ZIP دقیقاً همین است و سر جای خودش می‌نشیند.
3. **مایگریشن (الزامی، فقط یک بار):** پنل مدیریت → تنظیمات → دکمهٔ **«اجرای مایگریشن‌ها»** → باید اجرای `013_analytics_and_ai_logs`، `014_coords_source` و `020_business_comments` را ببینید (اگر بعضی قبلاً اجرا شده باشند، در فهرست «ردشده» می‌آیند — طبیعی است).
4. از پنل، **کش صفحات عمومی** را پاک کنید (تا همهٔ صفحات با بارنامهٔ `s18.0` دوباره ساخته شوند).
5. مرورگر را یک‌بار با **Ctrl+F5** تازه کنید (پنل ادمین هم خودش باندل تازه با هش جدید می‌خورد).

## ۶) تست‌های پیشنهادی بعد از نصب

- **گزارش جدید S18:** پنل → کسب‌وکارها → کارت کهربایی «مختصات پرریسک — مرکز پلی‌گون OSM» با تعداد موارد → «نمایش فهرست اصلاح مختصات» → یکی را «ویرایش» کنید → لینک گوگل‌مپ را در «Paste سریع» بریزید → «استخراج و اعمال» → پین منتقل شود → ذخیره → مورد از گزارش خارج شود و شمارنده کم شود.
- **مسیریابی S17:** صفحهٔ جزئیات یک کسب‌وکار → ۵ دکمهٔ «دسترسی سریع» (گوگل · جستجوی نام در گوگل · نشان · بلد · OSM) → بعد از کلیک، داشبورد آمار رویداد `map` باید بالا برود.
- **جستجو:** `/search?q=کافه` باید سالم و بدون خطای ۵۰۰ کار کند.
- **دیدگاه‌ها (S16):** صفحهٔ جزئیات → فرم دیدگاه با سؤال امنیتی → ثبت در تب جدید کار می‌کند.
- **آمار (S9):** داشبورد آمار بدون خطای «خواندن آمار ناموفق بود» باز شود.
- **پنل:** ویرایش کسب‌وکار → «نمایش نقشهٔ انتخاب مکان» → کشیدن پین → Lat/Lng زنده عوض شود؛ زیر فرم «منبع مختصات فعلی» نمایش داده شود.
- **بنر GIF (S8):** یک بنر GIF آپلود و در سایت متحرک ببینید.

## ۷) برگشت به عقب (Rollback)

محتوای `backup-s18/` را به همان مسیرها برگردانید و کش پنل را پاک کنید. مایگریشن‌های 013/014/020 فقط «افزودنی»اند (جدول و ستون جدید می‌سازند و چیزی را حذف یا تغییر معنایی نمی‌دهند)؛ با برگشت فایل‌ها به نسخهٔ قبل، همین ستون‌ها/جدول‌ها بی‌ضرر باقی می‌مانند و کد قدیمی آن‌ها را نمی‌خواند.

## ۸) نکات

- اگر قبلاً S16 یا S17 را نصب کرده‌اید، این بسته همان فایل‌ها را با نسخهٔ نهایی بازنویسی می‌کند — بی‌ضرر است و حالت نهایی دقیقاً یکی است.
- بعد از نصب این بسته، **هیچ‌کدام از بسته‌های افزایشی قبلی (S7 تا S17) را دوباره نصب نکنید**؛ این بسته از همهٔ آن‌ها جدیدتر است.
- دارایی‌های عمومی با `?v=s18.0` بارگذاری می‌شوند تا کش مرورگر و OPcache هاست به‌اجبارن تازه شود.
- فونت‌ها، آیکن‌ها و موتور نقشه همچنان ۱۰۰٪ لوکال‌اند (`font-display: swap`، بدون هیچ CDN) — مطابق قید همیشگی پروژه.
