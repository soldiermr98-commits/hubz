# ابزار یک‌بارمصرف برای اجرای واقعی API حامی‌هاب

این ابزار برای بررسی HTTP 500 مسیر `/api/v1/auth/me` است. برخلاف تست پایه، پس از واردکردن کد یک‌بارمصرف، فایل واقعی `public_html/api/index.php` را با همان مسیر GET اجرا می‌کند و پاسخ را خلاصه می‌کند. بدنهٔ خام و CSRF token نمایش داده نمی‌شوند. ابزار به نشست تصادفی و جداگانه نیاز دارد، `session.use_cookies` را برای همین درخواست خاموش می‌کند، مایگریشن اجرا نمی‌کند و هیچ تغییری در جدول‌های برنامه نمی‌دهد.

## اجرا

1. ZIP را روی رایانه باز کن و فایل `admin-api-entrypoint-diagnostic.php` را مستقیماً داخل `public_html` دامنه بارگذاری کن. مسیر نهایی باید `public_html/admin-api-entrypoint-diagnostic.php` باشد.
2. با HTTPS این صفحه را باز کن: `https://hamihubx.ir/admin-api-entrypoint-diagnostic.php`.
3. کد یک‌بارمصرفی را که جداگانه دریافت کرده‌ای داخل فرم وارد کن؛ کد را در URL ننویس.
4. گزارش محدود را ذخیره و برای عیب‌یابی ارسال کن. پس از اجرای کد معتبر، فایل خودش را حذف می‌کند. اگر خطایی دیدی یا فایل باقی ماند، بلافاصله آن را در File Manager حذف کن.

این ابزار فقط برای PHP 8.1 یا جدیدتر است. متن کامل fatal، مسیرهای مطلق، تنظیمات، رمزها و توکن نشست عمداً نمایش داده نمی‌شوند. موفقیت آن فقط اجرای واقعی همان API را در همان درخواست آزمایشی تأیید می‌کند و به‌معنی رفع دائمی خطای سرور نیست.
