# ابزار تشخیص یک‌بارهٔ API پنل Hamihub

این ابزار موقت برای عیب‌یابی خطای `/api/v1/auth/me` با HTTP 500 ساخته شده است. بررسی‌های آن محدود به نسخه و افزونه‌های PHP، فایل‌ها و نحو PHP، بارگذاری Bootstrap و تنظیمات (بدون نمایش مقادیر)، قابل‌فراخوانی بودن دو مسیر API، ساخت/خواندن/حذف یک نشست موقت و یک پرس‌وجوی فقط‌خواندنی `SELECT 1` است. هیچ مایگریشن، نوشتن در جدول‌های برنامه، نمایش رمز/تنظیمات یا فراخوانی سرویس خارجی ندارد.

## استفاده

1. ZIP را روی رایانه باز کنید و فقط `admin-api-diagnostic.php` را در ریشهٔ `public_html` دامنه بارگذاری کنید؛ مثلاً مسیر نهایی `public_html/admin-api-diagnostic.php` باشد.
2. با HTTPS همان نشانی را باز کنید: `https://hamihubx.ir/admin-api-diagnostic.php`.
3. کد یک‌بارمصرفی را که مدیر سایت جداگانه دریافت کرده داخل فرم وارد کنید. آن را به URL اضافه نکنید و با دیگران به‌اشتراک نگذارید.
4. گزارش محدود را ذخیره/کپی کنید. پس از اجرای مجاز فایل خودش را حذف می‌کند؛ اگر خطا داد یا فایل باقی ماند، فوراً آن را از File Manager پاک کنید.
5. گزارش فقط وضعیت مرحله‌ها، نوع خطا و نام فایل/شماره‌خط را نشان می‌دهد؛ با این حال، آن را فقط برای مسئول فنی/پشتیبانی هاست بفرستید.

به‌PHP 8.1 یا جدیدتر نیاز دارد. اگر قبل از نمایش فرم HTTP 500 دیدید، فایل را پاک کنید و از پشتیبانی هاست PHP-FPM Error Log همان زمان را بخواهید. این ابزار جایگزین گزارش خطای PHP-FPM نیست و موفقیت بررسی‌ها هم تضمین نمی‌کند که همهٔ درخواست‌های وب‌سرور درست کار می‌کنند.
